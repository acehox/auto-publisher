## 2. What the Service does

Auto Publisher publishes messages posted in Discord announcement channels to the servers that follow
them, automatically, so you do not have to press "Publish" on each message.

- You choose which announcement channels the bot publishes from.
- On the paid plan you can add rules that decide which messages get published, based on the
  message's text, its author, mentions it contains, and similar conditions.
- The bot reads the content of messages in the channels you have enabled in order to apply those
  rules. It does not store message content. See the [Privacy Policy](/privacy).

### 2.1 Technical requirements

The Service only works if all of the following are true. These are requirements of Discord's
platform, not choices we make, and the Service cannot function without them:

- You have a Discord account, and the server has an **announcement channel** (a channel Discord
  itself designates as such).
- To configure the Service for a server you need the **Manage Server** permission in that server.
- In each channel the bot publishes from, the bot's role must have **View Channel**, **Send
  Messages** and **Manage Messages**. Without Manage Messages, Discord will not allow publishing.
- The free plan covers up to **3 channels per server**. The paid plan removes that limit.
- **Discord permits a maximum of 10 published messages per channel per hour.** This is Discord's
  limit. Once a channel reaches it, further messages in that hour are not published.
- Both plans are published by the same bot through the same queue. What a paid subscription adds is
  **priority within that queue**: when there is a backlog, paid servers' messages are published
  before free servers'. We do not promise a delivery time on either plan — Discord's own rate limits
  decide that, and a busy period can delay any message.
- Where a message contains a link, we wait a few seconds before publishing so that Discord can
  generate the link preview first. Followers would otherwise receive the message without it.

We publish these requirements so you can check compatibility before subscribing. If your server does
not meet them, the Service will not do what you expect.
